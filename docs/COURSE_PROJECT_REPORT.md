## КІРІСПЕ

**Тақырыптың өзектілігі:** 
Қазіргі цифрлық заманда білім беру саласында заманауи ақпараттық технологияларды тиімді қолдану студенттердің оқу үлгерімі мен уақытты басқару (time-management) дағдыларын арттыруда шешуші рөл атқарады. Студенттердің күнделікті оқу процесінде кездесетін басты мәселелердің бірі — сабақ кестесінің, орындалуы тиіс үй тапсырмаларының, зертханалық жұмыстар мен дедлайндардың (тапсырма тапсыру мерзімдерінің) әртүрлі мессенджерлерде, дәптерлерде немесе әлеуметтік желі чаттарында шашыраңқы сақталуы. Ақпараттың бұлай ретсіз таралуы маңызды оқу тапсырмаларын өткізіп алуға, оқу үлгерімінің төмендеуіне және студенттерде стресстік жағдайлардың туындауына әкеледі. Бұл мәселені шешудің ең тиімді жолы — оқу кестесін, дедлайндарды, тапсырмалар прогресі мен статистиканы бір ыңғайлы мобильді қолданбада біріктіру.

**Курстық жобаның мақсаты:** 
Студенттерге арналған оқу кестесін жоспарлауға, тапсырма мерзімдерін бақылауға және оқу үлгерімінің статистикасын жүргізуге мүмкіндік беретін кроссплатформалы «Оқу Жоспары» мобильді қосымшасын әзірлеу.

**Міндеттері:**
1. Мобильді қосымшаларды әзірлеудің теориялық негіздерін, қолданыстағы ұқсас аналогтарды және қазіргі заманғы заманауи фреймворктерді зерттеу;
2. Қолданбаның архитектурасын, деректер моделдерін, пайдаланушы интерфейсін (UI/UX) Material 3 стандартына сай жобалау;
3. Жергілікті сақтау қоры бар (`SharedPreferences`) қауіпсіз авторизация (`SHA-256` + `Salt`), тіркелу және сессияны қалпына келтіру механизмін іске асыру;
4. Апталық сабақ кестесін, дедлайндары бар тапсырмалар менеджерін, прогресс статистикасын және профиль модульдерін дамыту;
5. Әзірленген мобильді қосымшаны функционалдық тестілеуден өткізу және пайдаланушы нұсқаулығын дайындау.

**Зерттеу нысаны:** Студенттердің оқу процесін ұйымдастыру және оқу уақытын жоспарлау жүйесі.

**Зерттеу пәні:** Flutter фреймворгі мен Dart бағдарламалау тілі негізінде кроссплатформалы мобильді қосымшаны әзірлеу құралдары мен әдістері.

**Практикалық маңыздылығы:** Әзірленген «Оқу Жоспары» мобильді қосымшасы студенттерге оқу процесін цифрлық форматта жүйелеуге, дедлайндарды өткізіп алмауға және білім алу сапасын арттыруға мүмкіндік береді.

## 1-БӨЛІМ. ТЕОРИЯЛЫҚ БӨЛІМ

### 1.1 Мобильді қосымшалар туралы жалпы түсініктер
Мобильді қосымшалар — смартфондар, планшеттер және басқа да портативті құрылғыларға арналып әзірленген бағдарламалық қамтамасыз ету. Қазiргi таңда мобильдi қосымшалар негiзгі үш архитектуралық түрге бөлiнедi:
1. **Natives (Нативті қосымшалар):** Белгілі бір операциялық жүйеге арналып арнайы тілдерде жазылады (Android үшін Kotlin/Java, iOS үшін Swift/Objective-C). Құрылғы аппараттық ресурстарымен жоғары интеграция береді, бірақ әр платформаға бөлек код жазуды талап етеді.
2. **Web/Hybrid (Веб және гибридті қосымшалар):** HTML5, CSS, JavaScript технологиялары негізінде WebView арқылы жұмыс істейді. Әзірлеу арзан, бірақ өнімділігі төмен.
3. **Cross-platform (Кроссплатформалы қосымшалар):** Бip гана код базасымен (Single Codebase) Android және iOS платформаларында бірдей жоғары өнімділікпен жұмыс істейтін заманауи шешімдер (Flutter, React Native).

«Оқу Жоспары» жобасында ресурстарды үнемдеу және екі операциялық жүйеде де бірдей жұмыс істеуді қамтамасыз ету үшін кроссплатформалы Flutter технологиясы таңдалды.

### 1.2 Қолданыстағы бағдарламалық шешімдерді шолу
Нарықтағы студенттерге арналған оқу жоспарлағыш қосымшаларға талдау жүргізілді:
* **Google Calendar:** Икемді күнтізбе, бірақ сабақ ауысымдарына, оқытушылар тізіміне және оқу дедлайндарына арнайы бейімделмеген.
* **Todoist / Trello:** Тапсырмаларды басқаруға өте ыңғайлы, бірақ апталық оқу кестесі мен сабақ аудиторияларын көрсету функционалы жоқ.
* **myStudyLife:** Шетелдік оқу жоспарлағыш. Функционалы жақсы, бірақ қазақ тіліндегі локализациясы жоқ, интерфейсі күрделі және отандық колледжар/университеттер жүйесіне бейімделмеген.

**Салыстырмалы талдау кестесі:**

| Критерий | Google Calendar | Todoist | myStudyLife | **Оқу Жоспары (Осы жоба)** |

| Қазақ тіліндегі интерфейс | Жартылай | Жоқ | Жоқ | **Толық қазақ тілінде** |
| Апталық сабақ кестесі | Жай оқиға ретінде | Жоқ | Бар | **Арнайы бейімделген** |
| Тапсырмалар мен дедлайндар | Бар | Өте жақсы | Бар | **Прогресс пайызымен** |
| Қауіпсіз жергілікті сақтау | Серверлік | Серверлік | Серверлік | **Офлайн жергілікті база** |
| Қолдану қарапайымдылығы | Орташа | Күрделі | Орташа | **Жоғары (Material 3)** |

### 1.3 Мобильді қосымшаларды әзірлеудің негізгі кезеңдері
Мобильді бағдарламалық өнімді жасау мынадай негізгі кезеңдерден тұрады:
1. **Аналитика және талаптарды жинау:** Мақсатты аудиторияны (студенттер) зерттеу, техникалық тапсырманы қалыптастыру.
2. **UI/UX жобалау:** Интерактивті прототиптер мен Material 3 компоненттерін жобалау.
3. **Архитектура мен бағдарламалау:** Код базасын құру, State Management, навигация және сервистерді жазу.
4. **Тестілеу:** Модульдік тестілеу (Unit testing) және UI сценарийлерін тексеру.

### 1.4 Әзірлеуде қолданылатын бағдарламалық құралдарды талдау
* **Flutter SDK & Dart Language:** Google компаниясы әзірлеген, реактивті UI фреймворгі. Dart тілі синтаксистік жағынан таза, асинхронды бағдарламалауды (`Future`, `async/await`) қолдайды.
* **Provider (`ChangeNotifier`):** Flutter-дегі ресми ұсынылатын күй басқару (State Management) кітапханасы.
* **GoRouter:** Декларативті маршрутизация, `StatefulShellRoute` арқылы төменгі табтардың күйін сақтау және `refreshListenable` арқылы маршруттарды қорғау (Auth Guard).
* **SharedPreferences:** Жергілікті деректер қоры (`Key-Value` сақтау) — пайдаланушы профилі мен сессиясын сақтайды.
* **Crypto (SHA-256 + Salt):** Парольдерді криптографиялық хэштеу құралы.

## 2-БӨЛІМ. БАҒДАРЛАМАЛЫҚ ӨНІМДІ ЖОБАЛАУ

### 2.1 Мобильді қосымша құрылымын әзірлеу
Қосымша **Layered Architecture (Қабатты архитектура)** үлгісінде жобаланды:

```
┌─────────────────────────────────────────────────────────┐
│                    Presentation Layer                   │
│         (Screens: Home, Schedule, Tasks, Stats)         │
└───────────────────────────┬─────────────────────────────┘
                            │ Reads State / Dispatches Actions
                            ▼
┌─────────────────────────────────────────────────────────┐
│                 State Management Layer                  │
│                (AuthProvider / Provider)                │
└───────────────────────────┬─────────────────────────────┘
                            │ Calls Service API
                            ▼
┌─────────────────────────────────────────────────────────┐
│                Domain & Business Services               │
│                 (AuthService & AppUser)                 │
└───────────────────────────┬─────────────────────────────┘
                            │ Reads / Writes Data
                            ▼
┌─────────────────────────────────────────────────────────┐
│                   Data Storage Layer                    │
│      (StorageService / SharedPreferences & Crypto)      │
└─────────────────────────────────────────────────────────┘
```

**Модульдік папкалар құрылымы:**
* `lib/core/` — Жалпы константалар (`storage_keys`), роутер (`app_router`), тақырыптар (`app_theme`, `app_colors`) және утилиталар (`validators`, `date_utils`).
* `lib/models/` — Деректер кластары (`AppUser`, `Lesson`, `TaskItem`, `Subject`, `NotificationItem`).
* `lib/services/` — Деректерді сақтау (`StorageService`) және авторизация логикасы (`AuthService`).
* `lib/providers/` — Күй басқару (`AuthProvider`).
* `lib/screens/` — UI экрандары (`auth`, `home`, `schedule`, `tasks`, `stats`, `profile`, `shell`, `splash`).
* `lib/widgets/` — Қайта қолданылатын UI компоненттер.

### 2.2 Әзірлеу құралдарының сипаттамасы
* **Әзірлеу ортасы:** Android Studio 2026 / Visual Studio Code.
* **Имитатор / Эмулятор:** Android Virtual Device (Pixel 7 API 34).
* **Синтаксистік талдаушы:** `flutter_lints 5.0.0` ережелер жиынтығы.

## 3-БӨЛІМ. ПРАКТИКАЛЫҚ БӨЛІМ (ЕНГІЗУ ЖӘНЕ СЫНАҚТАН ӨТКІЗУ)

### 3.1 Мобильді қосымшаның функционалдығын дамыту

**1. Қауіпсіз авторизация және SHA-256 + Salt хэштеу (`AuthService.dart`):**
```dart
static String hashPassword(String password, String salt) =>
    sha256.convert(utf8.encode(salt + password)).toString();

static String _generateSalt() {
  final random = Random.secure();
  final bytes = List<int>.generate(16, (_) => random.nextInt(256));
  return base64UrlEncode(bytes);
}
```

**2. Маршруттарды қорғау және авторизациялық бағыттау (`app_router.dart`):**
```dart
GoRouter createAppRouter(AuthProvider auth) {
  return GoRouter(
    initialLocation: AppRoutes.splash,
    refreshListenable: auth,
    redirect: (context, state) {
      final location = state.matchedLocation;
      if (!auth.initialized) {
        return location == AppRoutes.splash ? null : AppRoutes.splash;
      }
      final loggedIn = auth.isLoggedIn;
      if (!loggedIn && !publicRoutes.contains(location)) return AppRoutes.login;
      if (loggedIn && (location == AppRoutes.login || location == AppRoutes.register)) {
        return AppRoutes.home;
      }
      return null;
    },
    ...
  );
}
```

### 3.2 Әзірленген мобильді қосымшаны пайдалану ережелері мен тестілеу

**Қолдану сценарийі:**
1. **Іске қосу (Splash):** Қолданба ашылғанда `SplashScreen` арқылы `restoreSession()` орындалып, сақталған сессия тексеріледі.
2. **Тіркелу және Кіру:** Пайдаланушы аты-жөнін, email және пароль енгізеді. Валидаторлар тексеріп, қате болса SnackBar арқылы ескертеді.
3. **Навигация:** Басты бетте 5 таб орналасқан. Тапсырмаларды сүзгілеу (Белсенді/Орындалған), сабақ кестесін қарау және жаңа сабақ/тапсырма қосу әрекеттері орындалады.
4. **Сессияны аяқтау:** Профильдегі «Шығу» батырмасын басқанда растау диалогы шығып, жүйеден шығады.

**Тестілеу нәтижелері (`flutter test`):**
Жоба бойынша 17 авто-тест (парольдерді хэштеу, email валидациясы, дубликат тіркелуді бұғаттау, сессияны қалпына келтіру) орындалып, **100% сәтті өтті (`All 17 tests passed!`)**.

1. Мобильді бағдарламалаудың теориялық негіздері мен заманауи кроссплатформалы Flutter фреймворгінің мүмкіндіктері терең зерттелді.
2. `Layered Architecture` үлгісіне негізделген қолданба архитектурасы, деректер моделдері және Material 3 стандартына сай ыңғайлы UI/UX интерфейсі жобаланды.
3. Пайдаланушы құпиясөздерін `SHA-256 + Salt` арқылы криптографиялық шифрлау, `SharedPreferences` ішінде сақтау және `GoRouter` арқылы маршруттарды қорғау жүйесі енгізілді.
4. Апталық сабақ кестесі, дедлайндар сүзгісі бар тапсырмалар менеджері, үлгерім статистикасы және профиль модульдері іске асырылды.
5. Қолданбаның барлық негізгі функциялары автоматтандырылған тесттермен тексеріліп, 100% оң нәтиже көрсетті.

Жобаның практикалық маңыздылығы жоғары, оны одан әрі дамыту үшін екінші семестрде Firebase серверлік базасын интеграциялау және Push-хабарландырулар жүйесін енгізу ұсынылады.
