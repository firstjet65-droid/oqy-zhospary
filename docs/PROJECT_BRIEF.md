# Оқу Жоспары — жоба сипаттамасы

## Тақырып
Жеке оқу кестесін құру және тапсырма мерзімдерін бақылауға арналған мобильді қолданба әзірлеу.

## Өзектілігі
Студенттер сабақ кестесін, тапсырмаларды және мерзімдерді әртүрлі жерде сақтайды, сондықтан тапсырманы өткізіп алу жиі кездеседі. Бір қолданбада кесте мен мерзімдерді біріктіру оқу уақытын тиімді жоспарлауға көмектеседі.

## Мақсаты
Студентке оқу аптасын жоспарлауға және ешқашан мерзімді өткізіп алмауға көмектесу.

## Міндеттері
1. Интерфейс пен навигацияны жобалау.
2. Тіркелу, кіру, сессияны сақтау және шығуды жергілікті сақтаумен іске асыру.
3. Басты бет, кесте, тапсырмалар, статистика және профиль экрандарын жасау.
4. Қолданбаны екінші семестрдегі функционалдық дамытуға дайындау.

## Мақсатты аудитория
Колледж және университет студенттері.

## Негізгі функционалдығы
- Апталық оқу кестесі
- Мерзімі мен басымдығы бар тапсырмалар тізімі
- Прогресс статистикасы
- Еске салғыштар

Бірінші семестрде толық жұмыс істейтіні: Splash, тіркелу, кіру, сессияны сақтау, профиль, шығу, маршрутты қорғау. Қалған экрандар — жалған деректермен жасалған UI көрсетілімі.

## Технологиялар
| Технология | Неге таңдалды |
|---|---|
| Flutter (Dart, Material 3) | Бір код базасымен Android/iOS қолданбасы және дайын заманауи UI компоненттері |
| provider | Қарапайым және жеңіл күй басқару (ChangeNotifier), оқуға оңай |
| go_router | Декларативті навигация, төменгі табтар және авторизация бойынша маршрутты қорғау |
| shared_preferences | Серверсіз жергілікті сақтау; пайдаланушылар мен сессия осында сақталады |
| crypto | Құпиясөзді SHA-256 + кездейсоқ тұзбен хэштеу, ашық түрде сақтамау |

## Архитектура
```
Screens (UI) -> Providers (ChangeNotifier) -> Services -> Storage (SharedPreferences)
```
- **Screens** — тек интерфейс, сақтауға тікелей қол жеткізбейді.
- **AuthProvider** — кіру күйін сақтайды, роутерді `refreshListenable` арқылы жаңартады.
- **AuthService** — тіркелу, кіру, шығу, сессияны қалпына келтіру, хэштеу.
- **StorageService** — SharedPreferences үстіндегі жұқа қабат, қателерді ұстайды.
- Жалған деректер тек `lib/data/mock_data.dart` ішінде, барлық мәтін `lib/l10n/kk_strings.dart` ішінде.

## Қорғау сценарийі
Splash -> Тіркелу -> Кіру -> Басты бет -> Навигация (5 таб) -> Профиль -> Негізгі бөлім (Тапсырмалар) -> Шығу -> Қайта кіру
